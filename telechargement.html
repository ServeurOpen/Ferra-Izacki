⬇ Télécharger FERRA.exe

Comment jouer

1. Connecte-toi et télécharge
Crée un compte ou connecte-toi (ci-dessus), puis clique sur le bouton de téléchargement. Ton navigateur récupère un seul fichier : FERRA.exe.
2. Lance-le
Double-clique sur le fichier téléchargé (dans ton dossier Téléchargements). C'est une version de développement, non signée numériquement : Windows SmartScreen peut afficher un avertissement — clique "Informations complémentaires" puis "Exécuter quand même".
3. Joue
Ta partie se sauvegarde automatiquement sur ton ordinateur — garde le même fichier pour la retrouver.
💡 Astuce
Épingle le fichier ou crée un raccourci pour y revenir facilement. Le jeu est encore en développement actif : de nouvelles versions arriveront régulièrement, annoncées sur le forum.

Un problème au lancement ?

Passe sur le forum — section Support — ou écris-nous directement en contact, avec ton navigateur/système et le message d'erreur éventuel.
