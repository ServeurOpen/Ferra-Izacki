Recharger mes crédits

Les crédits servent à payer des jeux et du contenu dans le Launcher. Plus le pack est grand, moins le crédit coûte cher.

Chargement…

Connecte-toi pour recharger tes crédits.

Tes crédits sont liés à ton compte Izacki, le même sur le site et dans le Launcher.

Se connecter Créer un compte

Choisis un pack de crédits

Paiement par carte, via Stripe

Comment ça se passe

Paiement
Par carte, sur une page de paiement Stripe. L'authentification 3-D Secure peut être demandée.
Retour
Tu reviens sur cette page une fois le paiement terminé.
Solde
Il se met à jour dans le Launcher quelques secondes après le paiement.
Usage
Les crédits n'ont de valeur que dans l'écosystème Izacki : ce ne sont ni des espèces ni une cryptomonnaie.
Limites
Des plafonds d'achat par jour et par semaine existent.
